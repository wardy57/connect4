# Welcome to the Connect 4 game!

This Python-based project allows you to enjoy the classic Connect 4 experience with a two-player mode and an AI opponent using the minimax algorithm.

## To run the Connect 4 game, follow these steps:

### Clone the Repository:

git clone https://github.com/wardy57/connect4.git
cd connect-4-game

### Install Dependencies:

pip install pygame

### Run the Game:

python connect4.py

## Instructions

The game is played on a 7x6 grid.
Two players take turns dropping colored discs (yellow and red) from the top into any of the seven columns.
The goal is to connect four discs of the same color in a row, vertically, horizontally, or diagonally.
The game ends when a player achieves four in a row, or the grid is full (resulting in a draw).
If playing against the AI, it uses the minimax algorithm to make optimal moves. Adjust difficulty levels for a more challenging game.

## Game Features

Two-player mode for human vs. human gameplay.
AI opponent with adjustable difficulty levels.
Clean and intuitive user interface.
Visual indication of winning moves on the game board.
Error handling for invalid user inputs.
Easily customizable code for future enhancements.
